# NannyBasics has moved

NannyBasics now lives in **[NannyMUD/NannyMUD-mudlet](https://github.com/NannyMUD/NannyMUD-mudlet)**,
in the `basics` folder, together with the map.

Get it from the newest release there:
https://github.com/NannyMUD/NannyMUD-mudlet/releases/latest

If you have NannyBasics 0.2.0 or older installed, remove it under Toolbox → Package Manager and
install `NannyBasics.mpackage` from that release. From then on `nanny update` keeps it current.

This repository is archived and no longer updated.
